
## Task

В файле задан ориентированный граф в виде матрицы инцидентности.  
Есть ли в графе вершины, достижимые из всех других вершин?

Требования:

- Соблюдение принятого для выбранного языка стиля кодирования
- Модульные тесты (больше баллов) или хотя бы несколько примеров запуска 
- Комментарии к каждому публичному методу (функции) и классу (модулю)

## Usage

```bash
./script/run.sh
```
